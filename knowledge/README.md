# knowledge

這個資料夾是本 fork 的實驗紀錄，不屬於上游 repo。

| 檔案 | 性質 | 內容 |
|---|---|---|
| [measurement-protocol.md](measurement-protocol.md) | protocol | 在這台機器上「什麼數字才算數」的規則 |
| [experiment-log.md](experiment-log.md) | state | 每一筆量測：設定、數值、來源、判讀 |

兩者刻意分開：protocol 定義如何思考與驗證，state 放進度與數據。
**不要把實驗數字寫進 protocol 檔，也不要把方法論寫進 log。**

## 寫入一筆新實驗前

1. 讀 `measurement-protocol.md`。它的每一條都對應一次實際犯過的錯。
2. 變更前先寫下可證偽的假設（預期哪個可觀測量怎麼變、什麼現象代表假設錯）。
3. **先量測再下結論。** 數字未讀到之前欄位寫 `pending`，不要填預期值。
4. 差異小於噪音下限時寫「無法解析」，不寫成改善。

## 這份紀錄最該被讀的部分

不是效能數字，是兩筆標了 **⚠ 修正紀錄** 的條目（EXP-009、EXP-011）。
兩次都是用「跨次量測相減」推導成本歸因，兩次都得出錯誤結論，
其中一次還據此排錯了工作優先序。`measurement-protocol.md` §1 與 §2 就是為此而寫。

同樣值得一讀的是三筆**假設被推翻**的條目（EXP-006、EXP-012，以及 EXP-008 中
`channels` 無法擬合的發現）——被推翻的假設在這裡與成功的結果同等重要，
因為它們界定了方法的邊界。
